# Workpulse 360 📷

Medición de espacios con cámara 360° (Insta360, Ricoh Theta…): **distancias,
áreas y alturas reales desde una sola foto**, por trigonometría con la altura
de cámara conocida. Todo se procesa en el navegador — las fotos nunca salen
del dispositivo.

## Funciones

- 📏 Distancias · 📐 rutas y áreas · 📊 alturas de objetos
- 📋 Mediciones guardadas con colores, renombrables, persistentes por foto
- 🖼️ Varias fotos por sesión (habitaciones) con nombres (🏷️ Salón, Cocina…)
- 🗺️ Plano de planta a escala real: export **SVG, PNG y DXF (CAD)**
- 📊 Superficie total de la sesión (GLA) · 🖨️ informe imprimible/PDF · 📄 CSV

## Desarrollo

```bash
npm install
npm run dev      # http://localhost:5173
```

Cada push a `main` construye y publica automáticamente en GitHub Pages
(rama `gh-pages`).
